# Vi-ViDoRe: Vietnamese Visual Document Retrieval Benchmark

A governed, human-validated benchmark for Vietnamese visual document retrieval with ColPali/ColQwen baselines.

## 📋 Project Status

**Current Phase**: Governed benchmark candidate (not frozen)
- **Direction 1 (Adaptive Token Budgeting)**: Pilot baseline only, core contributions not implemented
- **Direction 2 (Vi-ViDoRe Benchmark)**: Governance architecture complete, blocked by 8 P0 freeze gates

See [PUBLICATION_READINESS_REVIEW.md](PUBLICATION_READINESS_REVIEW.md) for detailed audit.

## 🚀 Reproducibility Commands

### Build Governed Benchmark Candidate
```bash
# Full rebuild from registry
python scripts/05_build_governed_benchmark.py --reset-output

# Audit only (no rebuild)
python scripts/05_build_governed_benchmark.py

# Attempt freeze (fails until all gates pass)
python scripts/05_build_governed_benchmark.py --freeze
```

### Run Baselines on Governed Candidate
```bash
# Test split (default)
python scripts/03_run_baselines.py --split test

# Dev split
python scripts/03_run_baselines.py --split dev

# Skip Bi-Encoder (faster)
python scripts/03_run_baselines.py --skip_biencoder

# Disable ColPali visual
python scripts/03_run_baselines.py --run_visual=false

# Custom visual model revision
python scripts/03_run_baselines.py --visual_model vidore/colpali-v1.2 --visual_revision <commit-hash>
```

### Fine-tuning (Direction 1 - Experimental)
```bash
python scripts/04_train_adaptation.py \
  --model vidore/colpali-v1.2 \
  --train_split train \
  --dev_split dev \
  --epochs 3 \
  --lora_r 32
```

### Run Tests
```bash
# All tests
python -m pytest tests/ -v

# Specific test modules
python -m pytest tests/test_data_governance.py -v
python -m pytest tests/test_metrics.py -v
```

## ⚠️ Known Limitations

1. **Not Human-Validated**: Current qrels are automatically generated target pages, not graded human judgments
2. **Domain Imbalance**: Test set heavily skewed toward healthcare (699/888 queries)
3. **Missing Page Types**: Form/template, chart-heavy, and scanned page queries severely underrepresented
4. **Source Confounding**: Legal and financial domains each have only 1 source publisher
5. **No Significance Testing in Pilot**: Pilot metrics (ColPali 0.5175 macro nDCG@5) are for pipeline debugging only
6. **Adaptive Token Budgeting (Dir 1)**: No pooling, pruning, controller, or Pareto experiments implemented
7. **No Lockfile**: Python dependencies not pinned; use `pip freeze > requirements.lock` for reproducibility
8. **No Git History**: Workspace not a Git repository; no immutable code revision for citation
